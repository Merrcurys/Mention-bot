## О боте
Mention bot - это бот, который может оповещать всех пользователей в чате.

Бота можно найти и протестировать по этому адресу: [@fast_mention_bot](https://t.me/fast_mention_bot?start=c1686051798545-ds)

[Канал](https://t.me/merrcurys_software/41), где оповещаю об обновлениях бота.

## Функционал бота
1. `/help`, `/command` - справка по всем командам.

2. `/all`, `/here`, `/everyone` - позвать всех пользователей. 

3. `/access_toggle` - тумблер прав доступа к оповещениям.

4. `/names_visibility` - тумблер для видимости имен при оповещении.

5. Смена языка (ru / en).

6. Все ошибки бот отправляет в админский чат.

## Ограничения бота

Часть ограничений накладывает Telegram, часть — сам бот, чтобы не упираться в лимиты Telegram.

* **Не больше 5 упоминаний в одном сообщении.** Это ограничение Telegram: уведомление получают только первые 5 упомянутых в сообщении. Поэтому бот разбивает список на сообщения по 5 ссылок.
* **Не больше 50 упоминаний через `@username` в одном сообщении.** Это лимит Telegram на упоминания; даже если их больше, уведомления всё равно получат только первые 5.
* **Команда `/all` — не чаще одного раза в минуту на чат.** Это связано с антифлуд-защитой Telegram: при частой массовой отправке Telegram отвечает ошибкой `FLOOD_WAIT` и требует подождать. Паузу в 60 секунд бот держит принудительно.
* **До 75 участников.** Бот оповещает не больше 75 человек, без учёта отправителя команды, ботов и удалённых аккаунтов. Это ограничение выбрано самим ботом из-за лимитов Telegram на количество упоминаний в одном сообщении. В теории можно было и 100 участников взять, но 75 выбрано с запасом до лимита.

## Установка
Создание виртуального окружения

Для Linux
```
python3 -m venv venv
source venv/bin/activate
```
Для Windows
```
python -m venv venv
venv\Scripts\activate
```
Установка зависимостей:
```
pip install -r requirements.txt
```
Подготовка админского чата:

Добавьте бота в админский чат.

Заполните файл .env
```
API_TOKEN = <получить можно через @BotFather>
API_ID = <получить можно на https://my.telegram.org>
API_HASH = <получить можно на https://my.telegram.org>
ADMIN_CHAT_ID = <войдите в чат и скопируйте последние цифры в адресной строке браузере>
```
Запуск бота
```
python bot.py
```

## Установка через Docker

Запустите Mention Bot:
   ```bash
   docker-compose up -d
   ```
